# The Stillhouse — `hotel-booking-system`

A fictional 28-room boutique luxury retreat above the Great Rift Valley, Naivasha, Kenya — built as a complete reservation platform: public website, booking engine, M-Pesa payments, guest accounts and an operating dashboard.

**Status: M0 complete (2026-11-11). Documentation and repository hygiene only. No application code exists yet.**

- The visual frontend is generated by Arena.ai Code Arena and must pass `docs/HANDOFF_CHECKLIST.md` before it is committed to `apps/web/`.
- The backend (Express + Prisma + PostgreSQL) is built afterwards (M3+) and adapts to the accepted frontend.

## Layout

```
apps/web        ← future Arena frontend (M1)
apps/api        ← future Express backend (M3+)
packages/shared ← constants + zod schemas (both apps)
prisma/         ← schema + migrations (M3+)
tests/          ← integration/ (API) · e2e/ (Playwright)
docs/           ← source of truth (see above)
```

## Ground rules

- JavaScript ES modules everywhere. No TypeScript, no Next.js, no Drizzle, no Tailwind.
- Money: integer minor units + explicit `currency: "KES"`. API base: `/api/v1`.
- Demo/mock data is isolated; no fake success paths in production code.
- `.env` is never committed; see `.env.example` for key names.
- Milestone gates (M0–M7) are mandatory — no skipping ahead.
